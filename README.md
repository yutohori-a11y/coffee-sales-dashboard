# コーヒー売上台帳ダッシュボード

コーヒー専門店の売上CSVを集計し、期間・地域・商品で絞り込めるダッシュボードです。
外部ライブラリなし(Python標準ライブラリのみ)で動くローカルサーバーと、単一のHTMLファイルで構成されています。

## 使い方

1. Python 3 がインストールされていることを確認してください。
2. このフォルダで以下を実行します。

   ```bash
   python dashboard_server.py
   ```

3. 表示されたURL(既定では `http://127.0.0.1:8765/`)をブラウザで開きます。

Windowsでは `ダッシュボードを起動.bat` をダブルクリックするだけでも起動できます。

## できること

- **合計売上・取引件数・平均取引額** をKPIタイルで表示
- **月別推移**・**商品別ランキング**(カテゴリ別に色分け)・**カテゴリ別/地域別の内訳** をグラフ表示
- 上部のフィルターで **期間・地域・商品・CSVファイル** を絞り込み(複数選択・複数ファイルの合算表示に対応)
- ダッシュボード画面に **CSVファイルをドラッグ&ドロップ** すると、自動でフォルダに保存されて選択肢に追加されます

## CSVファイルの形式

以下の列構成のCSV(UTF-8)であれば、ファイル名を問わずこのフォルダに置くだけで自動検出されます。

```
日付,商品名,カテゴリ,地域,数量,単価,売上金額
2026-01-01,ドリップコーヒー12杯,食品,東京,1,1200,1200
...
```

## ファイル構成

| ファイル | 役割 |
|---|---|
| `dashboard_server.py` | ローカルサーバー(CSV検出・集計データの提供・アップロード受付) |
| `売上ダッシュボード.html` | ダッシュボード本体(ブラウザ側の表示・フィルター・グラフ) |
| `ダッシュボードを起動.bat` | サーバー起動とブラウザ表示をワンクリックで行うランチャー(Windows用) |
| `売上データ.csv` / `売上データ_4-6月_デモ.csv` | サンプル売上データ |
